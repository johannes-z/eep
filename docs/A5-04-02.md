# A5-04-02

## Profil

`A5-04-02` ist ein unidirektionales 4BS-Profil fuer einen kombinierten Temperatur- und Feuchtesensor.

| Eigenschaft       | Wert                                         |
| ----------------- | -------------------------------------------- |
| RORG              | `A5`                                         |
| Telegrammtyp      | 4BS                                          |
| FUNC              | `04`                                         |
| TYPE              | `02`                                         |
| Bezeichnung       | Temperature and Humidity Sensor              |
| Hersteller        | ...                                          |
| Temperaturbereich | `-20...+60 degC`                             |
| Feuchtebereich    | `0...100 % RH`                               |
| Kommunikation     | unidirektional, zyklische Messwerttelegramme |
| Nutzdaten         | 4 Byte, `DB3` bis `DB0`                      |
| Ausgang           | nur Messwerte, keine Befehle                 |

Das Profil ist fuer Sensoren gedacht, die Umgebungstemperatur und relative Luftfeuchte in einem 4BS-Telegramm uebertragen. Der Messwertsensor benoetigt keine Antwort des Empfaengers. Ein Gateway oder Raumcontroller kann die Telegramme empfangen und die Werte weiterverarbeiten.

## Telegrammbelegung

Die Datenbytes werden in der EnOcean-4BS-Reihenfolge `DB3`, `DB2`, `DB1`, `DB0` angegeben.

| Byte / Bits     | Groesse | Feld              | Bedeutung                            |
| --------------- | ------: | ----------------- | ------------------------------------ |
| `DB3.7...DB3.0` |   8 Bit | nicht verwendet   | wird fuer dieses Profil ignoriert    |
| `DB2.7...DB2.0` |   8 Bit | Relative Humidity | relative Luftfeuchte                 |
| `DB1.7...DB1.0` |   8 Bit | Temperature       | Umgebungstemperatur                  |
| `DB0.7...DB0.4` |   4 Bit | nicht verwendet   | reserviert                           |
| `DB0.3`         |   1 Bit | LRN Bit           | Teach-in- oder Datentelegramm        |
| `DB0.2`         |   1 Bit | nicht verwendet   | reserviert                           |
| `DB0.1`         |   1 Bit | T-Sensor (TSN)    | Verfuegbarkeit des Temperatursensors |
| `DB0.0`         |   1 Bit | nicht verwendet   | reserviert                           |

## Temperatur `DB1`

`DB1` wird linear auf den Messbereich `-20...+60 degC` abgebildet. Die Rohwerte `251...255` sind reserviert.

|     Rohwert | Bedeutung                 |
| ----------: | ------------------------- |
|   `0...250` | gueltig, `-20...+60 degC` |
| `251...255` | reserviert                |

Die Dekodierung lautet:

```text
Temperatur [degC] = (DB1 * 80 / 250) - 20
```

Damit entspricht ein Rohwert von `0` einer Temperatur von `-20 degC`, `62.5` einer Temperatur von `0 degC`, `125` einer Temperatur von `20 degC` und `250` einer Temperatur von `60 degC`.

Die Aufloesung des 8-Bit-Feldes betraegt rechnerisch `0.32 degC` pro Rohwert.

## Relative Luftfeuchte `DB2`

`DB2` wird linear auf `0...100 % RH` abgebildet.

|     Rohwert | Bedeutung               |
| ----------: | ----------------------- |
|   `0...250` | gueltig, `0...100 % RH` |
| `251...255` | reserviert              |

Die Dekodierung lautet:

```text
Relative Feuchte [% RH] = DB2 * 100 / 250
```

Damit entspricht ein Rohwert von `0` einer relativen Feuchte von `0 % RH`, `125` einer relativen Feuchte von `50 % RH` und `250` einer relativen Feuchte von `100 % RH`.

Die Aufloesung des 8-Bit-Feldes betraegt rechnerisch `0.4 % RH` pro Rohwert.

## LRN Bit `DB0.3`

Das LRN Bit unterscheidet ein Teach-in-Telegramm von einem normalen Datentelegramm:

| Wert | Typ                |
| ---: | ------------------ |
|  `0` | Teach-in-Telegramm |
|  `1` | Datentelegramm     |

Nur Telegramme mit `DB0.3 = 1` enthalten normale Messwerte. Bei einem Telegramm mit `DB0.3 = 0` darf `DB1`/`DB2` nicht als Temperatur-/Feuchtewert dekodiert werden, weil die Nutzdaten dann zur Teach-in-Information gehoeren.

`DB0.1` ist das T-Sensor-Bit (TSN). Der Wert `0` bedeutet, dass der Temperatursensor nicht verfuegbar ist; der Wert `1` bedeutet, dass er verfuegbar ist. Das Bit wird nicht als Temperatur- oder Feuchtewert interpretiert. Die Repository-Implementierung veroeffentlicht es als Home-Assistant-Diagnosewert `T-Sensor`. `DB0.2` und `DB0.0` sind nicht verwendet.

## Teach-in und Kommunikation

`A5-04-02` ist ein Sensorprofil ohne bidirektionale Befehlsrichtung. Ein Empfaenger muss daher keine Antwort zur Messwertuebertragung senden.

Fuer eine lokale Erkennung kann ein Gateway gueltige `A5`-Telegramme beobachten und anhand des LRN-Bits zwischen Teach-in und Daten unterscheiden. Bei aktivem 4BS-Teach-in sind die Profilinformationen im Teach-in-Telegramm zu dekodieren; ein Teach-in-Telegramm darf nicht wie ein Messwerttelegramm behandelt werden.

Das Profil definiert keine ausgehenden Stell- oder Konfigurationsbefehle. Temperatur und Feuchte werden ausschliesslich aus den eingehenden Datenbytes gelesen.

## Dekodierungsbeispiel

Das Telegramm mit Nutzdaten `00 7D 7D 08` wird so dekodiert:

| Feld    |      Rohwert | Ergebnis        |
| ------- | -----------: | --------------- |
| `DB3`   |       `0x00` | nicht verwendet |
| `DB2`   | `0x7D` = 125 | `50 % RH`       |
| `DB1`   | `0x7D` = 125 | `20 degC`       |
| `DB0.3` |          `1` | Datentelegramm  |

Das vollstaendige Nutzdatenfeld `00 7D 7D 08` entspricht somit:

```text
Temperatur:       20 degC
Relative Feuchte: 50 % RH
Telegrammtyp:     Daten
```

## Implementierungshinweise

- `RORG` muss `0xA5` sein.
- Die Nutzdatenlaenge muss genau vier Bytes betragen.
- `DB0.3` muss fuer ein Messwerttelegramm gesetzt sein.
- Rohwerte ueber `250` in `DB1` oder `DB2` sind reserviert und sollten nicht als Messwerte veroeffentlicht werden.
- `DB3` wird in diesem Profil nicht verwendet und darf fuer die Dekodierung ignoriert werden; `DB0.1` wird nur als Diagnosewert `T-Sensor` (TSN) veroeffentlicht. `DB0.2` und `DB0.0` sind zu ignorieren.
- Das Profil ist read-only; ein Gateway darf keine A5-04-02-Stellbefehle erzeugen.
- Die Messwerte koennen als zwei Home-Assistant-Sensoren mit den Geraeteklassen `temperature` und `humidity` veroeffentlicht werden.
