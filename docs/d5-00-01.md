# D5-00-01 - Single Input Contact

## Quelle

EnOcean Equipment Profiles (EEP), Version 2.6.8, Dec 31, 2017, page 28.

## Profilkennung

| Feld      | Wert                  |
| --------- | --------------------- |
| RORG      | `D5`                  |
| Telegramm | 1BS Telegram          |
| FUNC      | `00`                  |
| Funktion  | Contacts and Switches |
| TYPE      | `01`                  |
| Typ       | Single Input Contact  |

## Kommunikationsmerkmale

- Richtung: unidirectional
- Telegrammtyp: 1BS
- Die LRN-Information ist vom Kontaktwert getrennt und belegt `DB0.3`.

## Datenfeld

| Offset | Size | Bitrange | Data         | ShortCut | Description | Valid range                    |
| -----: | ---: | -------- | ------------ | -------- | ----------- | ------------------------------ |
|      4 |    1 | DB0.3    | Learn Button | LRN      | -           | `0`: pressed; `1`: not pressed |
|      7 |    1 | DB0.0    | Contact      | CO       | -           | `0`: open; `1`: closed         |

## Teach-in

The 1BS telegram has its own teach-in telegram. The LRN bit is `DB0.BIT_3`. An LRN value of `0` identifies a teach-in telegram; an LRN value of `1` identifies a data telegram.

For the general 1BS teach-in procedure, see [teach-in.md](teach-in.md).
